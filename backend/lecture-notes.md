### **3. Detailed Explanation**  
*(Technical, AKTU-Aligned Summary)*  

#### **A. Cyber Threats & Their Impact**  
- **Definition**: Unauthorized access, data theft, system disruption, or malicious code execution.  
- **Examples**:  
  - *Phishing*: Fraudulent emails tricking users into revealing passwords (e.g., "Urgent account verification" link).  
  - *Ransomware*: Encrypting data and demanding payment (e.g., Colonial Pipeline attack in 2021).  
- **AKTU Focus**: How threats target *Indian* systems (e.g., Aadhaar data breaches, banking fraud via SMS phishing).  

#### **B. Cybersecurity Measures**  
- **Technical Controls**:  
  - *Encryption*: Protects data in transit (TLS) and at rest (AES-256).  
  - *Firewalls*: Network security systems blocking unauthorized access (e.g., AWS WAF).  
- **Procedural Controls**:  
  - *Multi-Factor Authentication (MFA)*: Mandatory for critical systems (reduces 99% of account takeovers).  
  - *Regular Audits*: To detect misconfigurations (e.g., open ports in cloud environments).  
- **AKTU Relevance**: Must align with **India’s DPDP Act 2023** for data protection compliance.  

#### **C. Data Privacy Laws (Indian Context)**  
- **DPDP Act 2023**: India’s first comprehensive data protection law.  
  - *Key Provisions*: Data localization, consent requirements, breach notification within 72 hours.  
  - *AKTU Exam Focus*: How this law impacts B.Tech projects (e.g., student data handling in apps).  
- **GDPR Comparison**: GDPR (EU) vs. DPDP Act (India) – differences in data residency, penalties (₹25 lakh/₹4% of global turnover).  

#### **D. Incident Response Process**  
1. **Detection**: SIEM tools flag anomalies (e.g., unusual login attempts).  
2. **Containment**: Isolate affected systems (e.g., disconnect network segment).  
3. **Eradication**: Remove malware, patch vulnerabilities.  
4. **Recovery**: Restore data from backups; validate system integrity.  
5. **Post-Mortem**: Document lessons for future prevention (required under DPDP Act).  
- *AKTU Case Study*: How a 2022 Indian bank breach was mitigated using this process.  

#### **E. Ethical Hacking & Penetration Testing**  
- **Legal Scope**: Only permitted with explicit authorization (per **Section 43 of IT Act 2000**).  
- **Tools**: Metasploit, Kali Linux, Burp Suite.  
- *AKTU Practical*: Students must conduct *authorized* tests on lab environments (no real systems).

### **4. Important Definitions**  
*(Critical for AKTU Exams)*  

| Term                 | Definition & AKTU Context                                                                 |
|----------------------|----------------------------------------------------------------------------------------|
| **Malware**          | Malicious software (e.g., viruses, trojans) designed to harm systems. *Example*: Emotet banking trojan targeting Indian SMEs. |
| **Ransomware**       | A type of malware that encrypts data and demands payment (e.g., Bitcoin) for decryption. *AKTU Focus*: DPDP Act mandates breach notification within 72 hours post-incident. |
| **Phishing**         | Deceptive attempts to steal credentials via fake emails/links. *Indian Context*: SMS phishing for mobile banking fraud. |
| **Data Breach**      | Unauthorized disclosure of sensitive data (e.g., 10M+ user records exposed in 2023 Indian app). |
| **Incident Response Plan (IRP)** | Predefined steps for handling security incidents (required under DPDP Act). |
